1 Overview

This replaces NESE_FemaleRepeatabilityIsotopes.Rmd. The question — do females tracked more than once keep their individual foraging pattern? — is addressed with four complementary analyses:

  1. Strategy fidelity: do repeat females keep the same strategy more often than expected by chance? (permutation test; Cohen’s κ)
  2. Behavioural repeatability: repeatability (R) of the main behavioural axes and of interpretable variables, from mixed models with year as a random effect (rptR).
  3. Spatial fidelity: is the overlap between two trips of the same female higher than between trips of different females? (randomisation test on utilisation distributions)
  4. Isotopic consistency: population-level repeatability of δ¹³C and δ¹⁵N (adjusted for trip type, with year as a random effect), and a comparison of within-female isotopic differences with differences between different females sampled in the same years.

What changed from the previous script, and why. The “individual repeatability” index (between-individual variance / (between-individual variance + one seal’s residual variance)) is not a defined quantity: per-seal variances from 2–4 samples are extremely noisy, and conditional residuals from the mixed model are shrunk towards each seal’s mean, pushing the index towards 1. The previous script also attached those values to the wrong seals (ddply returns seals in alphabetical order, which were then relabelled in data order) and dropped one female through hard-coded row indices. Isotopes alone also cannot detect switching between the two offshore strategies, which are isotopically very similar. Repeatability is therefore estimated here only at the population level, and fidelity is tested directly on behaviour and space.

Run first: NESE_PB_ForagingStrategies.Rmd, NESE_PM_ForagingStrategies.Rmd (strategy assignments) and NESE_SpatialStrategies.Rmd (individual UDs).

2.1 Helper functions

# Cohen's kappa for two vectors of categorical labels
cohen_kappa <- function(a, b) {
  lev <- union(a, b); a <- factor(a, lev); b <- factor(b, lev)
  tab <- table(a, b); n <- sum(tab)
  po <- sum(diag(tab)) / n; pe <- sum(rowSums(tab) * colSums(tab)) / n^2
  (po - pe) / (1 - pe)
}

# Fit rptR::rpt() without printing its progress bars into the report
fit_rpt <- function(...) {
  out <- NULL
  invisible(capture.output(out <- rpt(...)))
  out
}

# Read one random-effect component (e.g. "MainID") from rptR's printed summary.
# rptR's object layout differs between versions; the printed summary does not.
rpt_parse <- function(r, comp) {
  txt <- capture.output(print(summary(r)))
  i <- grep(paste0("^\\s*", comp, " \\("), txt)[1]
  if (is.na(i)) return(NULL)
  k <- grep("Repeatability estimation overview", txt)
  k <- k[k > i][1]
  if (is.na(k)) return(NULL)
  hdr  <- strsplit(trimws(txt[k + 1]), "\\s+")[[1]]
  vals <- suppressWarnings(as.numeric(strsplit(trimws(txt[k + 2]), "\\s+")[[1]]))
  if (length(hdr) != length(vals)) return(NULL)
  setNames(vals, hdr)
}

# One row of results: female repeatability (R, CI, P) and the share of variance due to year
rpt_row <- function(r, label, n_obs, n_ind, n_rep) {
  v  <- if (is.null(r)) NULL else rpt_parse(r, "MainID")
  vy <- if (is.null(r)) NULL else rpt_parse(r, "Year")
  g  <- function(x, nm) if (!is.null(x) && nm %in% names(x)) unname(x[[nm]]) else NA_real_
  if (is.null(v) && !is.null(r)) { message("Could not read R for ", label, "; full output:"); print(summary(r)) }
  data.frame(variable = label, n_obs = n_obs, n_females = n_ind, n_repeat_females = n_rep,
             R = g(v, "R"), SE = g(v, "SE"), lwr = g(v, "2.5%"), upr = g(v, "97.5%"),
             P_LRT = g(v, "LRT_P"), P_permut = g(v, "P_permut"),
             R_year = g(vy, "R"), P_LRT_year = g(vy, "LRT_P"))
}

# Draw one element at random (safe when x has length 1, unlike sample())
pick1 <- function(x) x[sample.int(length(x), 1)]

# All within-female pairs of rows of d (columns: MainID, TOPPID, trip, year, ...)
within_pairs <- function(d) {
  d %>% group_by(MainID) %>% filter(n() > 1) %>%
    group_modify(function(g, key) {
      ij <- t(combn(nrow(g), 2))
      data.frame(TOPPID_1 = g$TOPPID[ij[, 1]], TOPPID_2 = g$TOPPID[ij[, 2]],
                 trip_1 = g$trip[ij[, 1]], trip_2 = g$trip[ij[, 2]],
                 year_1 = g$year[ij[, 1]], year_2 = g$year[ij[, 2]])
    }) %>% ungroup() %>%
    mutate(pair_type = ifelse(trip_1 == trip_2, paste0(trip_1, "-", trip_2), "PB-PM"),
           lag_years = abs(year_2 - year_1))
}

5.3 Repeatability (rptR)

Model: y ~ Trip + (1 | MainID) + (1 | Year). R is the adjusted repeatability (between-female variance over the sum of the random-effect and residual variances, with trip type as a fixed effect). All tracked females are used; females tracked once help estimate the variance components, but the between-female variance is informed by the repeat females (17 here), so CIs are wide.

6 3. Spatial fidelity

Bhattacharyya’s affinity (BA) between the utilisation distributions of two trips of the same female, compared with BA between trips of different females of the same pair type. Two nulls:

  • Population null: the second trip is replaced by a random trip of the same type from a different female. Tests whether females return to their own areas rather than just to the population’s area.
  • Strategy null (same-type pairs only): the replacement trip is drawn from the same strategy. Tests fidelity beyond strategy membership.
if (file.exists(UD_FILE)) {
  ud <- readRDS(UD_FILE)
  P  <- cbind(ud$P_pb, ud$P_pm)
  ud_meta <- bind_rows(ud$seals_pb %>% transmute(TOPPID, trip = "PB", strategy),
                       ud$seals_pm %>% transmute(TOPPID, trip = "PM", strategy)) %>%
    left_join(trk %>% transmute(TOPPID, MainID = as.character(MainID)), by = "TOPPID") %>%
    filter(!is.na(MainID))
  P  <- P[, ud_meta$TOPPID, drop = FALSE]
  BA <- crossprod(sqrt(P))

    mutate(BA = BA[cbind(TOPPID_1, TOPPID_2)])

9 Suggested Methods text

We assessed whether females tracked on more than one trip kept their foraging pattern with four complementary analyses. (1) Strategy fidelity: for each pair of trips by the same female we recorded whether she used the same strategy (for post-breeding–post-moult pairs, the same offshore region), and compared the number of consistent pairs with a null distribution obtained by permuting strategy labels among trips of the same type (9,999 permutations); we also report Cohen’s κ. (2) Behavioural repeatability: after standardising behavioural variables within trip type, we summarised them by principal component analysis and estimated the adjusted repeatability of the first two components and of maximum latitude, California Current use and distance to the continental shelf with linear mixed models including trip type as a fixed effect and female and year as random effects (rptR; Stoffel et al. 2017; parametric bootstrap CIs and permutation tests). (3) Spatial fidelity: we compared the overlap (Bhattacharyya’s affinity) between utilisation distributions of two trips of the same female with that obtained when one trip was replaced by a random trip of the same type from a different female, and, for pairs of the same trip type, from a different female of the same strategy (9,999 randomisations). (4) Isotopic consistency: we estimated the adjusted repeatability of δ¹³C and δ¹⁵N with trip type as a fixed effect and female and year as random effects, and compared absolute isotopic differences between samples of the same female with those between different females sampled in the same years and trip types (9,999 randomisations).
